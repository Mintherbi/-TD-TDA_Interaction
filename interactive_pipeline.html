Stage 2: Latent Space Representation

About Latent Space

The latent space represents the collective state of all neurons at each time point. We visualize 3 selected units as axes in 3D space. As time progresses, each neural state becomes a point, and the trajectory traces the evolution through this space.

Stage 3: PCA 3D Projection

About PCA

Principal Component Analysis (PCA) reduces the high-dimensional neural data to 3D while preserving maximum variance. The trajectory shows how neural states evolve over time in this reduced space.

Stage 4: UMAP 2D Manifold

About UMAP

Uniform Manifold Approximation and Projection (UMAP) further reduces PCA results to 2D while preserving local and global structure. This reveals the intrinsic manifold geometry of neural dynamics.

Stage 5: 1D Spanning Tree

About Spanning Tree

The minimum spanning tree connects all time points in UMAP space, creating a 1D structure that represents the temporal evolution of neural states. This tree topology reveals the fundamental trajectory through state space.
